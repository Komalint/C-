🚀 Welcome to ASP.NET Web API (C# .NET Framework)

An API (Application Programming Interface) is like a waiter in a restaurant: it takes requests from clients (this webpage, mobile apps, or Postman), tells the C# backend what to do, and brings back data in lightweight JSON format!

🔍 GET = Read ✚ POST = Create ✏️ PUT = Update 🗑 DELETE = Delete 📄 Output: JSON
